# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticize ideas and code rather
than people, and no harassment of any kind.

Reports go to the maintainers through a private GitHub security advisory on
this repository until a dedicated contact is published here.
